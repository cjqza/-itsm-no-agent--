# 操作系统常见问题

## 电脑蓝屏怎么办

蓝屏通常由以下原因导致：
1. 驱动冲突或过时
2. 系统文件损坏
3. 硬件故障（内存、硬盘）
4. 软件兼容性问题

**解决步骤：**
1. 记录蓝屏错误代码（如 0x0000007B）
2. 重启电脑，按 F8 进入安全模式
3. 在安全模式中卸载最近安装的软件或驱动
4. 运行系统文件检查：打开命令提示符（管理员），输入 `sfc /scannow`
5. 如果问题持续，请提交工单由工程师处理

## 电脑卡顿怎么办

卡顿可能由以下原因导致：
1. 内存不足
2. 硬盘空间不足
3. 后台程序占用过多资源
4. 病毒或恶意软件

**解决步骤：**
1. 按 Ctrl+Shift+Esc 打开任务管理器
2. 查看 CPU 和内存占用最高的程序
3. 关闭不必要的后台程序
4. 清理磁盘空间（至少保留 10% 可用空间）
5. 运行杀毒软件扫描

## 如何修改开机密码

**Windows 系统：**
1. 按 Ctrl+Alt+Delete，选择"更改密码"
2. 输入当前密码
3. 输入新密码并确认
4. 点击"确定"

**Mac 系统：**
1. 点击苹果菜单 → 系统偏好设置
2. 选择"用户与群组"
3. 点击"更改密码"

## 如何连接公司WiFi

1. 点击任务栏右下角的 WiFi 图标
2. 选择公司 WiFi 名称（如 "Company-Guest" 或 "Company-Staff"）
3. 输入公司提供的 WiFi 密码
4. 如果无法连接，请检查是否需要 VPN

## 如何安装常用软件

**通过公司软件中心：**
1. 打开"软件中心"或"公司应用商店"
2. 搜索需要的软件
3. 点击"安装"

**手动安装：**
1. 从公司内部下载站获取安装包
2. 双击运行安装程序
3. 按照提示完成安装
4. 注意：部分软件需要管理员权限，请提交工单申请

## 打印机无法打印

**检查步骤：**
1. 确认打印机电源已开启
2. 检查打印机是否有纸张和墨水
3. 确认电脑与打印机在同一网络
4. 检查打印队列是否有堆积任务

**解决方法：**
1. 重启打印机
2. 清空打印队列：控制面板 → 设备和打印机 → 右键打印机 → 查看打印队列 → 取消所有文档
3. 重新安装打印机驱动
4. 如果问题持续，请提交工单

## 邮件无法发送

**检查步骤：**
1. 确认网络连接正常
2. 检查收件人地址是否正确
3. 检查附件大小是否超过限制（通常 10MB）

**解决方法：**
1. 检查发件箱是否有堆积邮件
2. 清理发件箱后重试
3. 检查邮箱存储空间是否已满
4. 联系IT支持检查邮件服务器状态
